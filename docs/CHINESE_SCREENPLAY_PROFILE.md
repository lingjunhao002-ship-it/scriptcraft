# 中国大陆影视剧本排版档案（首版规范）

> 状态：中文档案、文本度量、初版换行、布局、egui 预览、PDF 字体加载入口、Fountain 中文标题识别和 FDX profile 往返代码已提交。字体尚未随仓库打包，Windows/Rust CI 尚未确认通过；当前不属于已验收版本。
>
> 本档案面向中国大陆电影、电视剧和网络剧的常见文学剧本。行业并不存在适用于所有制片方、平台、导演和征稿活动的唯一排版标准；交付时必须优先使用接收方给定的模板。

## 1. 首版默认文稿结构

1. 封面：片名、剧本类型/集数、编剧、版本和日期。
2. （可选）主要人物表：人物名、身份/关系和必要的简短说明。
3. 正文：按场次顺序组织；每场至少包含场号、内/外景、时间和地点。
4. 正文元素：场景标题、动作描述、人物、括号说明、对白、转场、镜头/一般说明。
5. 长篇电视剧可按集、幕或序列组织；结构标题不应被误解析为普通对白。

## 2. 场景标题与正文样例

推荐首版识别和呈现如下写法（具体标点可由项目模板调整）：

```text
1. [内] 夜  咖啡馆

△ 雨点敲打玻璃。林晚推门进来，收起湿透的伞。

林晚
（压低声音）
你确定东西在这里？

周明
在。刚刚有人来找过你。

（门外传来刹车声。）
```

解析约定：

- 场号是场次稳定的制作标识，正文中应保持唯一；重排场次时提供重编号/锁号策略。
- 内/外景、日/夜、地点是场景标题的重要组成部分；输入时允许“1. [内] 夜 咖啡馆”“1、咖啡馆。夜。内”等可配置形式。
- 动作、人物名、对白、括号说明、转场和镜头描述应分别存为不同的文档元素。
- “△”是常见动作段落视觉标记，但不是所有团队都要求；应由模板控制，不强制插入到每一段动作前。
- 人物名和对白分行呈现；括号说明可独立成段，也可作为对白块内的段落，须保留文档结构。
- 中文文本不应被自动转成全大写；拉丁字母缩写和英文角色名可按原文保留。

## 3. 首版页面与文字度量

下列数值是产品默认起点，不宣称是行业强制标准；须允许模板覆盖并按实际交付样稿校准。

| 项目 | 首版默认 |
|---|---|
| 纸张 | A4（210 × 297 mm） |
| 页面边距 | 上/下 1 英寸，左/右 1 英寸 |
| 正文字号 | 12 pt（可配置；提交方模板优先） |
| 行高 | 14.4 pt（1.2 倍；可配置） |
| 正文 | 中文全角字符按一个 em 度量；拉丁字母/数字按字体实际 advance 度量 |
| 对齐 | 正文左对齐；人物名和转场按元素模板设置 |
| 页码 | 正文页连续编号；封面是否计页由模板决定 |

注意：中文影视项目存在宋体、黑体、字号、行距、首行缩进、页码位置等多种交付要求。某些征稿活动甚至指定宋体小四、段首空两字、页码底端居中。首版档案不应把单一字体或“△”符号硬编码为唯一规则。

## 4. 字体与授权

- 首选评估 Noto Sans SC（简体中文）或 Noto Serif SC（衬线），由应用随包嵌入，确保 Windows 和 PDF 字形一致。
- Noto CJK 的当前许可说明为 SIL Open Font License 1.1；发布时必须固定具体字体版本、字体文件、LICENSE、版权声明和 ATTRIBUTION 记录。
- 必须检查字体嵌入/子集化、可复制文本、简繁字形、全角标点、拉丁混排、粗体/斜体、缺字回退和文件体积。
- 不允许仅依赖用户电脑上的“微软雅黑”或系统字体；便携版与 PDF 输出必须有确定的字体来源。

## 5. 排版与分页规则

- 按字体实际 advance 进行排版；不得将每个 Unicode 字符简单视为等宽。
- CJK 行首禁则：不得以常见右括号、句号、逗号、顿号、分号、冒号、问号、叹号等开头。
- CJK 行尾禁则：尽可能避免左括号、左引号等开头符号落在行尾。
- 中文、ASCII、全角空格、半角空格、组合附加符号、emoji 和扩展汉字需要分别测试。
- 场景标题尽量与后续至少一行动作/对白保持在同页。
- 对白块分页不得丢失人物名或括号说明；中文格式不默认添加好莱坞式 (MORE)/(CONT'D)。
- 页码、页眉页脚、场号和 PDF 坐标必须与屏幕预览一致。

## 6. 兼容性

- 选择中文档案不应改变 Fountain/FDX 的底层文本编码或破坏原有段落元素。
- 现有 ScriptCraft 文档在没有 profile 字段时继续按 Hollywood 档案打开。
- 用户切换档案时明确提示会应用对应元素格式与纸张设置；切换回 Hollywood 时也要恢复其默认设置。
- 项目模板允许保存 profile、纸张、字号、行高、字体、边距、元素缩进、标题规则和页码规则。

## 7. 验收样本

至少包括：
- 纯中文长动作段落与中文长对白。
- 中英混排、数字、英文缩写和括号。
- 全角/半角标点、连续引号、破折号、省略号。
- 场景标题跨页、长对白跨页、括号段落跨页。
- 多集/多幕标题、重编号场次、锁定场号。
- PDF 字体嵌入、文本复制、页面尺寸与页码。
- Windows 10/11 x64 离线启动、便携版运行、路径含中文。

## 8. 参考依据

- 清华大学出版社《电视编辑实用手册》关于中国大陆格式常先标场号，再标地点、内外景、时间，并说明正文顺序可调整的介绍。
- 中国政法大学相关影视文学课程材料强调场景应标明地点、日/夜、内/外景和人物，并指出剧本格式需服务拍摄。
- 不同征稿/制片单位可能另行规定宋体、字号、段首缩进和页码位置，因此项目模板优先级高于本档案默认值。


## 9. 当前字体提供方式（开发/验收用）

首版开发代码从以下位置寻找经许可再分发的简体中文 OpenType 字体：

1. 系统环境变量 `SCRIPTCRAFT_CJK_FONT` 指向一份可供本程序合法使用和嵌入的 OTF 字体，例如在 PowerShell 中：`$env:SCRIPTCRAFT_CJK_FONT = "D:\\fonts\\NotoSansSC-Regular.otf"`。
2. 未设置环境变量时，原生应用查找可执行文件旁的 `fonts/NotoSansSC-Regular.otf`。

运行前必须自行取得真实、受信任的字体文件并确认其许可；**目前 GitHub 仓库没有随附该字体文件**。若中文 PDF 导出找不到可用的字体，导出返回 `PdfError::Font`，不会默默输出缺失汉字的 Courier PDF。输入文件必须由字体解析器可读取；暂不保证 TTC/变量字体格式都能使用。

这是供开发测试的临时接入方式。发布 Windows 安装包时应固定 Noto Sans SC 的精确版本与来源，将已审计的静态字体与 OFL 许可文件和 ATTRIBUTION 一并纳入分发，并验证签名、字形覆盖与子集嵌入。

### 已知限制

- 现有东亚宽度是近似的全角/半角单元宽度，**不是**真正的字体 shaping/字体实际 advance；复杂 emoji、连字、字距调整可能仍与 PDF 字体度量不同。
- 括号、标点避头尾是初版启发式，不应视作完整 UAX #14 实现；下一阶段评估 `unicode-linebreak` 等成熟 Rust 库或兼容字形分段方案。
- 画布中注释、修订范围、双人对白等附加层仍含固定 Courier 度量，需要继续迁移。
- CJK PDF 暂用一份 regular 字体渲染多种字重；真正的粗体/斜体支持要等多字重字体资源可用后完成。
- Fountain 不能天然保存所有分页与字体参数；FDX 通过 `ScriptCraftFormat ScreenplayProfile` 扩展保存档案标识。第三方 FDX 编辑器可能忽略本扩展。
- 中文人物名的自动识别目前只针对简短汉字姓名，较长艺名和带角色标注的非标准写法应让用户显式指定人物段落。
